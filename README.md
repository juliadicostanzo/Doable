# Doable

Doable is a React Native task-management application designed to make managing tasks and deadlines feel more doable.

## Preview

[SCREENSHOT]

## Features

- Create and organize tasks
- Assign tasks to categories
- Track task due dates
- View tasks in a calendar
- Mark tasks as completed
- Track overall completion progress

## Technologies

- JavaScript
- React Native
- Expo

## Running the Project

1. Clone the repository
2. Install dependencies:

   npm install

3. Start Expo:

   npx expo start
